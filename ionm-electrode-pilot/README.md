# Single-Use IONM Stimulation Electrode: Pilot Production and Process Validation

**Status:** Built | **Year:** 2026
**Stack:** SolidWorks, process FMEA, IQ/OQ/PQ

SolidWorks design and BOM of a stainless-steel needle stimulation electrode with silicone/TPE-insulated lead and touch-proof DIN 42802 connector. Small pilot batch built by crimping and soldering after a design-for-manufacturing review. Process FMEA, IQ/OQ/PQ validation plan (crimp pull-out, continuity, insulation, impedance), assembly work instruction, sterile-barrier packaging concept (ISO 11607 / ISO 11135, concept only).

Personal project, not employer or customer work.

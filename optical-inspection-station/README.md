# Optical Component Final-Inspection Station

**Status:** Built | **Year:** 2026
**Stack:** Python, OpenCV, Excel, SPC

USB-microscope inspection of lenses and windows for scratch-dig defects (ISO 10110-7) with OpenCV detection, bench check of centring and focal length, and an Excel test protocol with an SPC control chart.

Personal project, not employer or customer work.

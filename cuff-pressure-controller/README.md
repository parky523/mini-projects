# Cuff Pressure Controller with ISO 14971 Risk File and IEC 62366 Usability File

**Status:** In progress | **Year:** Oct 2026 - present
**Stack:** ESP32, C++, ISO 14971, IEC 62366

ESP32 controller (pressure sensor, mini pump, solenoid valve) that holds a set cuff pressure with over-/under-pressure, leak and timer alarms, presets and CSV logging. Accompanied by an ISO 14971 risk file and an IEC 62366-1 usability file.

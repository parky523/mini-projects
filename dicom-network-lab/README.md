# Imaging Network Lab: DICOM / PACS Service Practice

**Status:** Built and working | **Year:** 2026
**Stack:** Orthanc, DICOM, HL7, Linux networking

PC and Raspberry Pi lab with an Orthanc PACS and two DICOM nodes (C-ECHO, C-STORE), static IP/VLAN configuration, SSH/VNC remote access, simulated network faults with log-based fault-finding, Modality Worklist and HL7 message flow, plus a requirements spec, test plan and rollout checklist.

Personal project, not employer or customer work.

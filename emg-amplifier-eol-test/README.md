# 2-Channel EMG Amplifier Board + End-of-Line Test Station

**Status:** Built | **Year:** 2026
**Stack:** KiCad, LabVIEW/Python, oscilloscope, signal generator

2-channel EMG front-end (instrumentation amplifier, filtering) with KiCad schematic, PCB layout and BOM. Test concept: a signal generator injects reference signals; oscilloscope plus a LabVIEW/Python script gives an automated pass/fail on gain, CMRR and noise. IEC 60601-1 touchpoints (leakage, isolation) are treated as a design/test concept only, not compliance testing.

Personal project, not employer or customer work.

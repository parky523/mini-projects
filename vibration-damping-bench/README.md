# Active Vibration Damping Test Bench

**Status:** In progress | **Year:** 2026
**Stack:** ESP32, MATLAB/Simulink

Cantilever-beam bench with accelerometer and voice-coil actuator on an ESP32 loop: impact-hammer modal analysis, system identification in MATLAB, passive vs active (PID/LQR) damping, Simulink hardware-in-the-loop.
